## Установка изменений в репозиторий

Это архив изменённых файлов, а не отдельный полный проект. Распакуйте архив на рабочий стол и скопируйте содержимое папки DLYA_SVOIH_v0.3.119 в существующую DLYA_SVOIH_GITHUB с заменой соответствующих файлов.

После копирования в PowerShell:

```powershell
Set-Location "$env:USERPROFILE\Desktop\DLYA_SVOIH_GITHUB"
git status --short
$files = Get-Content .\docs\READER_119_FILES.txt
git add -- $files
git commit -m "Rewrite card descriptions for readers; v0.3.119"
git push origin main
```

Затем на GitHub откройте Actions → Build and publish APK → Run workflow. Branch: main. Поле tag оставьте пустым. Поле changes: «Переработаны описания карточек; служебные сведения перенесены в источники. Версия 0.3.119». Запустите workflow.

Используется прежний ANDROID_DEBUG_KEYSTORE_BASE64; менять его не требуется. Workflow выпустит app-0.3.119 и обновит latest.json. В установленном приложении откройте «Обновления» и установите 0.3.119 поверх 0.3.118. При первом запуске встроенное содержимое 149 заменит прежнее 148. Идентификатор приложения, схема и таблицы пользовательских данных сохранены; избранное и история сохраняются при установке APK с прежней подписью.

## Контроль на телефоне

Откройте ПМН-2, ТМ-62М, M795 и семейство HPD. Перед таблицей должны быть связные описания. В основном тексте отсутствуют «Сведения о наполнении», журналы переноса и «Примечания к источнику». Кнопка «Показать» у «Источников» открывает документы и сохранённые примечания. Проверьте ранее добавленное избранное.
