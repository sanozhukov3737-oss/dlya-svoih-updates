# ТТХ: v0.3.56

Добавлены физические характеристики в 5 карточек: ЛМГ, Model 1953, Model 1954, Mle 1951 и Mle 1955. Основной источник — TM 5-280 / OP 3121 Rev 1 / AFTO 60H-1-1-1 (1971). Названия группы M1951/1955 дополнительно сверены с FM 3-34.2 (2002), Appendix B, Table B-6. Таблицы прочитаны по сканам оригинала.

Для ЛМГ подтверждена масса по таблице (стр. 6-111); размеры в ней отсутствуют. Для Model 1954 приведены приблизительная масса и размеры из общей таблицы Models 1953 and 1954 (стр. 9-35). Model 1953 — парное изделие: в её карточке добавлены только размеры отдельного элемента, без выдачи 2 lb за массу всей пары. Полная масса пары остаётся неподтверждённой.

Для Mle 1951 и Mle 1955 явно обозначена область данных: общая таблица противопехотной осколочной группы Model 1951/55 (стр. 9-43). Она не является отдельной спецификацией каждой модификации и не относится к французским противотанковым или фугасным минам с тем же годом в названии. Высота дана по общей таблице; полная высота с выступающим стержнем отдельно не подтверждена.

В этой партии не добавлены новые данные МДМ, современных американских выстрелов и Arsenal: первичные страницы не удалось получить. Значения из поисковых отрывков и соседних моделей не перенесены. Техническая полнота всех карточек не заявлена.

Аудит охватывает 1287 карточек. В разделе боеприпасов остаются 135 записей без раздела характеристик, включая общие статьи и неподтверждённые обозначения. Все записи перечислены в ALL_CARDS_TTX_AUDIT.csv. Наличие ТТХ не означает полноту всех параметров.

Версия приложения 0.3.56 (versionCode 60), версия содержимого 98. База собрана SQLite 3.45.1.

Проверки: 15 локальных тестов; целостность SQLite и внешних ключей; соответствие тел карточек и источников JSON и базе; сохранение идентификаторов, изображений и остальных полей; повторное применение обновления не меняет каталог; целостность ZIP и контрольные суммы файлов.

Сборка APK и запуск на Android в этой среде не выполнены.

```powershell
.\MAKE_APK.bat
```

```powershell
explorer.exe ".\app\build\outputs\apk\debug"
```
