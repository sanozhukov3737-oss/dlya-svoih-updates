# Обновление ТТХ v0.3.83

Проверены источники ещё 19 карточек боеприпасов. В 16 добавлены новые числовые сведения; в трёх повторно проверены прежние показатели или границы источника. Добавлены 87 строк, включая ограничения, и 11 новых разделов ТТХ. Данные о массе основного ВВ внесены в девять карточек с оговорками о варианте, номинальной массе и составе комплекта; это не девять полностью заполненных паспортов.

Всего проверены источники 909 из 1287 карточек. Осталось 378: 335 боеприпасов, 6 ПТРК, 17 СВО и 20 медицинских карточек. Среди оставшихся боеприпасов 70 пока без раздела ТТХ. Проверка источников не означает полностью заполненные характеристики.

Добавлены наружные параметры четырёх компонентов Elbit; расхождение M82T/T82M оставлено явно. Для ТМ-62П, ТМ-62Д, ТМ-62П2 и ТМ-62Т основное наполнение разделено по вариантам. У ОЗМ-160 отделены массы мины и снаряда; диаметр по фланцу исправлен относительно ошибочного распознавания скана. Три тротиловые шашки имеют номинальную массу основного наполнения, без подмены полной массы с обёрткой. У ТМ-73 масса основного заряда относится к компоненту, не ко всем узлам комплекта. Параметры ЧМВ разделены по трём индексам и состоянию измерения; наружные размеры №8-А/М не назначены №8-С/Б. Данные ПДМ-1М не перенесены на ПДМ-1.

Версия приложения 0.3.83, код 87, версия содержимого 125. База пересобрана; проверены точное воспроизведение обновления и повторное применение без изменений. Пройдены 15 локальных тестов. Сохранены прежние исправления открытия базы и удаления верхнего повторного описания. APK здесь не собирался, запуск на Android не проверялся.

Из распакованной папки проекта в PowerShell:

```powershell
.\MAKE_APK.bat
explorer.exe ".\app\build\outputs\apk\debug"
```

## Проверка комплекта

1287 карточек, 53 страны, 39 категорий, 987 записей изображений. Сохранены все 910 файлов изображений. Сверены четыре страницы заводских PDF, 17 изображений оригинальных страниц и одна официальная страница ARCUS. Для руководств МО СССР проверены конкретные сканы страниц, а не заявлено чтение полного PDF; оригинальное пособие 2014 года этим не заменено. Новые таблицы содержат только справочные наружные размеры, массы и основное наполнение с указанием границ источника.

Прежние источники и все остальные поля карточек сохранены. Проверены точное применение, повторный запуск без изменений, совпадение JSON и SQLite, integrity_check, foreign_key_check и версия содержимого. Архив сверяется по CRC и контрольным суммам всех файлов; предыдущие файлы сохраняются, кроме перечисленных обновляемых данных и метаданных версии. APK и проверка на устройстве не заявлены.
