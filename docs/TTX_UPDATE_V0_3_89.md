# Обновление ТТХ v0.3.89

Проверены ещё 36 карточек боеприпасов. Добавлены 77 строк характеристик и ограничений источников. В 31 карточке есть новые числовые сведения; в 30 внесены массы основного ВВ, в том числе значения для конкретных вариантов и отдельно подписанные максимальные массы. Все эти числовые сведения о наполнении атрибутированы ранее предоставленному справочнику «Иностранные мины 2». Повторная сверка книги не объявлена независимым подтверждением изготовителем или полным современным паспортом.

Источники проверены для 1075 из 1287 карточек. Осталось 212: 180 боеприпасов, два ПТРК, десять СВО и 20 медицинских карточек. Среди оставшихся боеприпасов 57 без распознаваемого раздела ТТХ. Статус проверки означает выполненную сверку доступного источника, а не заполненность всех характеристик. Карточки с отмеченными пробелами остаются кандидатами для дальнейшего поиска.

По изображениям и тексту собственных таблиц сверены BM/85, PP-Mi-Na, Pansermine M/56, PM-87, MI AC DISP F1, PT Mi-D1M, TMD-1, VS-SATM1, SB-MV/1, VS-HCT4, VS-AT4EL, BAT/7, APILAS / APAJAX, Addermine / AJAX, ARGES, VS-T, VAR/IG, MI ECL CB 58, MI ECL LDU F1B, VS-TA 90 и IMZR-11. Для ARGES добавлен калибр гранаты, но марка и масса основного ВВ не найдены в собственной таблице. Для пяти сигнальных моделей явно отмечено отсутствие сведений о марке и массе пиротехнического наполнения; для VS-TA 90 там также отсутствуют масса изделия и внешние размеры. В этих пяти карточках новые числа не заявлены.

Для Pansermine M/56 значение 7,2 кг сохранено как буквальная масса основного ВВ из собственной таблицы; оно не перенесено на все национальные исполнения AC ID 51/52. У VS-SATM1 таблица разделена между страницами 146 и 147, а таблица SB-MV/1 принадлежит следующей статье. У VS-HCT4 проверена собственная таблица, а не предыдущая VS-HCT. Для APILAS масса комплекта, масса гранаты и масса её основного наполнения записаны раздельно. Для Addermine / AJAX также отделена масса основного наполнения гранаты. Латинское HMX для IMZR-11 проверено по изображению.

Сверены 15 морских моделей или семейств: MINEA, BGM 100 / Rockan, BGM 601 / Banny, BGM 600, BMM 80, Quickstrike, Quickstrike-ER, MN 105 / Seppia, MR 80, MP 80, MN 102 / Murena, Asteria, MO-90, Stonefish и Sea Urchin. В MINEA числовое наполнение указано только для цилиндрической модели; на коническую, якорную и учебную версии оно не перенесено. В BGM 601 буквально сохранены 80 кг из верхней таблицы страницы 254, с пометкой отсутствия независимого подтверждения. В BGM 600 значения 200, 300 и 400 кг из нижней таблицы этой страницы перечислены раздельно и не суммированы. Прежнее замечание об ошибочном имени BGM 100 в следующем абзаце сохранено.

Колонки Quickstrike Mk 62 / Mk 63 / Mk 65 и MR 80 Mod A / Mod B / Mod C проверены раздельно. Для Quickstrike-ER 429 кг относятся к исполнению из таблицы с полной массой 908 кг и без точного индекса. Официальное сообщение U.S. Pacific Fleet от 19.09.2018 различает два весовых класса QSER, но не подтверждает массу наполнения из справочника. Значение 429 кг не объявлено общим для всей серии. Запросы двух других официальных страниц вернули 403 и не засчитаны как успешная проверка.

Для Asteria значения 200, 400 и 600 кг не усреднены и не привязаны каждое к одной общей массе 1050 кг. В MO-90 и Sea Urchin сохранено буквальное указание массы одного основного заряда без вычисления суммарного наполнения других исполнений. В Stonefish максимальная масса основного ВВ Mk II и Mk III подписана как максимум, а не фактическое наполнение любого корпуса. Обозначения ТГ и PBX оставлены без рецептур; отсутствующая марка ВВ не придумана.

Версия приложения 0.3.89, код 93, содержимое 131. База пересобрана; проверены воспроизведение изменения и повторное применение без изменений, совпадение JSON и SQLite, integrity_check и foreign_key_check. Все 15 локальных тестов пройдены. Исправления открытия локальной базы и удаления верхнего повторного описания сохранены. APK здесь не собирался и запуск на Android не проверялся.

Из распакованной папки проекта в PowerShell:

```powershell
.\MAKE_APK.bat
explorer.exe ".\app\build\outputs\apk\debug"
```
