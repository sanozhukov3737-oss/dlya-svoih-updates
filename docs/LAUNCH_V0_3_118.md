# Заставка v0.3.118

Приложение 0.3.118, versionCode 122. Каталог №148, 1293 карточки.

На записи телефона с v0.3.117 фон и значки строки состояния уже отображались правильно, но надпись под силуэтом была обрезана. Предыдущая проверка размеров ресурса этого дефекта не выявила.

## Изменение

`launch_mark.xml` теперь является настоящим VectorDrawable, а не layer-list с bitmap. Вектор сохраняет существующий силуэт и слово «ДЛЯ СВОИХ», использует launch_ink и имеет внутренние поля для системной маски. Тот же вектор используется в LaunchPreview на Android 8–11. Механизм ожидания первого кадра и переход к каталогу сохранён.

## Проверки

- Локальная сборка :app:assembleDebug успешна; 40 проверок прошли.
- Android SDK проверил packageName ru.dlyasvoih.app, versionName 0.3.118, versionCode 122 и minSdk 26.
- Инструмент публикации обработал переход 121 → 122 с прежним локальным тестовым сертификатом и сохранил поля канала каталога.
- Встроенная база и content/catalog.json совпадают с v0.3.117; база внутри APK совпадает с исходным файлом.

В APK с помощью aapt2 подтверждён корневой тип vector у launch_mark.xml. Локальный APK 118 установлен в AOSP Android 12 (API 31). Однако полноэкранную визуальную проверку не удалось завершить: эмулятор без аппаратного ускорения показывал ANR системного лаунчера и System UI, перекрывающие запуск. Такой результат не считается успешной визуальной проверкой. Отдельное тестовое приложение с неизменёнными ресурсами заставки столкнулось с тем же ограничением среды. Отображение на телефоне пользователя требует проверки после публикации.

Предварительный просмотр вектора с круговой маской выполнен отдельно; это проверка ресурса, а не снимок экрана Android. Изображение: LAUNCH_PREVIEW_V0_3_118.png.

## Публикация

Загрузить изменения в main, запустить существующий GitHub Actions build-apk.yml. Использовать прежний ANDROID_DEBUG_KEYSTORE_BASE64. После успешной публикации app-0.3.118 открыть «⋮ → Обновления» в установленной v0.3.117 и установить обновление приложения. Локальный APK собран для проверок тестовым ключом и в архив не включён.
