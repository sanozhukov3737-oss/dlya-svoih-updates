# Обновление ТТХ v0.3.82

Проверены источники ещё 26 карточек боеприпасов. В девяти добавлены новые числовые сведения с указанием границ источника; в остальных 17 повторно сверены прежние показатели, обозначения и отсутствие паспортных полей в проверенных документах. Добавлены 74 строки, включая проверку и ограничения, и 6 новых разделов ТТХ. Сведения о массе основного ВВ добавлены в шесть карточек, включая явно противоречивую запись FMK-1; это не шесть однозначно подтверждённых паспортов.

Всего проверены источники 890 из 1287 карточек. Осталось 397: 354 боеприпасов, 6 ПТРК, 17 СВО и 20 медицинских карточек. Среди оставшихся боеприпасов 81 пока без раздела ТТХ. Проверка источников не означает полностью заполненные характеристики.

Добавлены исторические размерные поля и основное наполнение четырёх чилийских мин; колонка металлического содержимого не принята за полную массу. Для Vibhav добавлены наружные размеры, полная масса и название основного ВВ по DRDO. Размеры M662 относятся к отдельному модулю. Для M393 разделены полный выстрел, боевые A1/A2 и учебный TP-T A1. Данные раннего XM94 не выданы за паспорт поздних SLAM M2/M4. В FMK-1 явно отмечено противоречие форм H.1/H.2; для спорных PMB и сгруппированного PROM-KD сохранены ограничения обозначений.

Версия приложения 0.3.82, код 86, версия содержимого 124. База пересобрана; проверены точное воспроизведение обновления и повторное применение без изменений, 15 локальных тестов пройдены. Сохранены прежние исправления открытия базы и удаления верхнего повторного описания. APK здесь не собирался, запуск на Android не проверялся.

Из распакованной папки проекта в PowerShell:

```powershell
.\MAKE_APK.bat
explorer.exe ".\app\build\outputs\apk\debug"
```

## Проверка комплекта

1287 карточек, 53 страны, 39 категорий, 987 записей изображений; все 910 файлов основного изображения сохранены. Сверены 12 отдельных страниц PDF, 6 визуально проверенных изображений страниц и 2 текстовых источника. Для FMK-1 проверена публичная текстовая копия государственного отчёта; оригинальный PDF не заявлен прочитанным. Таблицы FM 3-34.2 не содержат наружных масс, размеров и масс наполнения: проверка их обозначений не равна заполнению этих полей.

Изменены только тексты и добавленные источники перечисленных карточек. Прежние источники сохранены, остальные поля, изображения и карточки совпадают с предыдущей версией. Сверены JSON и SQLite, integrity_check и foreign_key_check, версия содержимого, точное применение и повторный запуск. Архив проверен по CRC, контрольным суммам всех файлов и сохранности предыдущих файлов. Android SDK в этом окружении для сборки не использовался; APK и проверка на устройстве не заявлены.
