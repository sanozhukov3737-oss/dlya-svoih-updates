# ТТХ: v0.3.52

Проверено наличие раздела характеристик во всех 1287 карточках.

Добавлены таблицы физических характеристик по источникам в 199 карточек. В 42 карточках существующие таблицы массы и размеров перенесены под заголовок ТТХ. Всего изменена 241 карточка. ПТМ-4 и все 17 карточек авиационных боеприпасов включены.

У каждой добавленной таблицы есть источник и конкретная страница. Для выстрелов, снарядов, пусковых труб и контейнеров указана комплектация. Масса упаковки и наполнения не подменяет массу изделия. Дюймы, фунты и унции сопровождаются метрическими пересчётами. Неоднозначные строки источников не перенесены как подтверждённые значения. Наличие таблицы не означает полноту всех параметров: у отдельных моделей подтверждены только размеры.

Полное заполнение каталога ещё не завершено. Без отдельного раздела характеристик остаётся 221 карточка раздела боеприпасов. Ещё 28 записей без такого раздела — медицинские памятки, общие статьи и инструкция ПТРК. Полный список и ссылки на источники: ALL_CARDS_TTX_AUDIT.csv. Проверка наличия раздела не является независимой проверкой каждого старого числового значения.

Проверки: 15 локальных тестов; целостность SQLite; соответствие JSON и базы; отсутствие изменения идентификаторов, изображений и остальных полей карточек; повторное применение правки не меняет каталог. База собрана SQLite 3.45.1, contentVersion 94.

Сборка Android и запуск на устройстве в этой среде не выполнены.
