# 0.3.139 — необязательные 3D-модели и уведомления

Статус: подписанный APK и проверки Android 8 / 16 прошли. [Файлы выпуска](https://github.com/sanozhukov3737-oss/dlya-svoih-updates/releases/tag/app-0.3.139).

615 наружных визуальных моделей вынесены из APK в отдельный пакет. Все GLB побайтно совпадают с проверенной коллекцией 0.3.138; геометрия, текстуры, авторство, лицензии и оговорки сохранены. В APK остаются средства просмотра и небольшой реестр для поиска. Размер первого подписанного APK — около 106 МБ вместо 1,39 ГБ. Каталог 197, все 1695 карточек и 1595 изображений сохранены.

## Управление коллекцией

Меню → «3D-модели · офлайн» → «Скачать 615 моделей». По умолчанию включено ограничение «Только Wi-Fi». Android продолжает скачивание в фоне; процесс можно отменить. Каждая попытка получает отдельный временный файл, поэтому очистка отменённой загрузки не затрагивает повторную. После полной проверки SHA-256 пакет атомарно становится активным. Он хранится одним сжатым файлом без распаковки второго комплекта почти на 2 ГБ. При открытии каждая GLB также проверяется по собственному SHA-256. WebView по-прежнему не имеет сетевого или файлового доступа.

«Управление» → «Удалить модели» освобождает место, сохраняя карточки, фотографии, тему, избранное и место чтения. Коллекцию можно скачать снова. При замене текущий пакет сохраняется до полной проверки нового; отмена или повреждённая загрузка не удаляют установленную коллекцию. Пакет не входит в облачную резервную копию.

После перехода с 0.3.138 встроенные в старый APK модели больше не занимают установщик. Новая версия сама не скачивает коллекцию: пользователь выбирает, нужна ли она.

Пакет 1: 1283096387 байт, SHA-256 `7780860bcb82fc23a861f162a66d99fb8950a66508275919ee7bf9c1b6b9147d`. Он опубликован отдельно в `models-pack-1` и не изменяет текущий стабильный канал приложения. Каноническое описание файлов — `content/model-pack-1.json`.

## Уведомления

В разделе «Обновления» добавлен выключатель уведомлений о новых версиях приложения и каталога. Фоновая задача проверяет доступные версии примерно раз в шесть часов при наличии сети; точное время выбирает Android. Одной версии соответствует одно уведомление. Нажатие открывает раздел обновлений. APK не скачивается и не устанавливается автоматически.

На Android 13 и новее разрешение запрашивается после нажатия «Включить уведомления». На главной показывается небольшое предложение с кнопкой «Позже»; включение также доступно в разделе обновлений. Отказ не мешает пользоваться справочником или проверять обновления вручную. Для запрета в настройках Android есть отдельная ссылка. После перезагрузки и замены APK расписание сохраняется или восстанавливается.

## Сборка

```bash
python3 tools/prepare_optional_models139.py
bash gradlew :app:assembleRelease
```

Подготовка восстанавливает точный реестр 615 моделей из gzip и закреплённое описание пакета. Gradle копирует в ресурсы APK всё, кроме GLB. Защита сборки не допускает старый частичный реестр. Закрытый ключ остаётся в существующем секрете Actions. Для нового пакета используется отдельный архив; самостоятельно устанавливать ZIP не требуется.

Сертификат: `2f0a0908f269bc039311edb58fca8863347f1e4c3a7cfaddd909991cf1f0b509`.

- Семь проверок архива прошли без ошибок: контрольные суммы, состав ZIP, отсутствующие или изменённые модели, лишние пути, отмена и ограничение памяти.
- На ускоренных эмуляторах Android 8 / API 26 и Android 16 / API 36 установлены точные подписанные APK 0.3.138 и 0.3.139. Сохранены ID/rowid всех карточек, 1595 изображений, избранное, место чтения, тёмная тема и метаданные.
- Приложение работает без пакета. На обеих системах пройдены отмена, установка, настоящий просмотр и вращение, отклонение повреждённой замены, удаление с освобождением **1283100672 байт**, повторная установка и чтение всех 615 GLB через рабочий загрузчик с проверкой каждого исходного SHA-256.
- На Android 16 весь архив 1,28 ГБ скачан настоящим DownloadManager. При свёрнутой галерее проверку и подключение завершили получатель системного события и фоновая задача, без опроса из интерфейса. На Android 8 для проверки содержимого использован тот же закреплённый архив.
- Для native-проверок установлен debug APK из той же сборки с той же подписью. Затем повторно установлен точный оптимизированный release APK: проверены внешний пакет, начальный и повёрнутый кадры без сети и сохранность данных.
- Уведомления о тестовых будущих версиях приложения/каталога появились без повторов; выключатель отменяет задачу и уведомления. После завершения instrumentation обычное нажатие на настоящее уведомление открыло раздел обновлений. На Android 16 проверен системный запрос разрешения по кнопке. Будущие номера существуют только на тестовых эмуляторах; публичное предложение каталога 197 не меняется.

GLB, материалы, текстуры и скрипт отрисовки моделей не менялись. Полная визуальная проверка 1230 кадров Android из 0.3.138 дополнена проверками нового хранилища и настоящими кадрами текущей сборки. Физический телефон в этой сессии не проверялся.
