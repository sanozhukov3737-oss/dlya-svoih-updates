# Кандидат 0.3.138

Статус: локальные проверки пройдены; подписанная сборка, Android и визуальная проверка ожидаются. Не является объявлением готового выпуска.

Полный APK: versionCode 143, 615 офлайн-моделей, 511 привязок к карточкам. Прежние 19 GLB и 596 новых GLB сохраняются побайтно. Все 1695 карточек каталога 197 и изображения сохраняются. 44 спорных визуала доступны в общей коллекции с пояснениями; точных привязок для них нет. Поиск в коллекции, выбор вариантов у карточки, отдельные раскрываемые сведения и проверенные HTTPS-ссылки.

Для 0.3.137 и более ранних выпусков нужен небольшой совместимый APK с versionCode 142: он сохраняет прежние 19 моделей, добавляет поддержку APK до 2 ГиБ и предложения `appLarge`. Общая лента сохраняет в `app` этот небольшой переходный APK; новый загрузчик предпочитает `appLarge` с полным APK. Прямая установка полного APK поверх 0.3.137 не требует переходного APK. Предел каталога остаётся 256 МиБ; закрытый ключ подписи не меняется.

Исходный реестр с авторством, лицензиями и оговорками: `content/models-0.3.138.json.gz` (обычный gzip JSON, без потери сведений). GLB хранятся в архиве `models-0.3.138-assets.zip` в черновике выпуска `models-0.3.138-inputs`; его размер, SHA-256 и все контрольные суммы включены в `app-0.3.138-inputs.json`. Для подготовки локальных ресурсов: `python3 tools/prepare_models138.py --archive /path/to/models-0.3.138-assets.zip`. Затем стандартная Gradle-сборка. GitHub Actions получает архив через штатный доступ репозитория.

Проверки до публикации: подпись прежним сертификатом, 615 GLB в полном APK, 19 GLB в переходном, 1230 настоящих Android-кадров (начальный и повёрнутый вид), просмотр кадров, прямая установка и переход 141 → 142 → 143 с сохранением данных. Публикация запускается отдельно после подтверждения результатов.
