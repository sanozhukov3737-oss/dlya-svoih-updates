## Исходные модели и воспроизведение сборки

Реестр с авторством, лицензиями, режимом окраски и оговорками: `content/models-0.3.138.json.gz`. GLB находятся в архиве `models-0.3.138-assets.zip` предварительного выпуска `models-0.3.138-inputs`. Размер, SHA-256 архива и контрольные суммы файлов закреплены в `app-0.3.138-inputs.json`.

```bash
python3 tools/prepare_models138.py --archive /path/to/models-0.3.138-assets.zip
bash gradlew :app:assembleRelease
```

Подготовка создаёт полный `models.json` и компактный `card-index.json`, проверяя 615 GLB и исходную базу. Сборка отказывается создавать частичный APK из свежего checkout с прежними 19 моделями. GitHub Actions восстанавливает архив по закреплённому ID и SHA-256. Закрытый ключ остаётся в существующем секрете Actions и не входит в архивы, исходники или отчёты.
