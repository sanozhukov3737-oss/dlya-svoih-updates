# ТТХ: v0.3.54

Добавлены таблицы физических характеристик в 33 карточки: 6 артиллерийских/гранатомётных выстрелов и снарядов из TM 43-0001-28; 6 гранат из полного издания TM 43-0001-29 с поправками до 2002 года; 17 карточек мин и взрывателей из USAREUR Pam 30-60-1 (1975); 3 мины из TM 5-280 (1971); Panzerfaust 3 по официальной странице Bundeswehr.

Для каждого источника указаны конкретные страницы или раздел. Перенесены масса изделия и габариты. Масса наполнения и упаковки не используется вместо массы изделия. Для M101 сохранены две комплектации, для M84 — приблизительная масса со взрывателем, для PP-MI-SR — масса без взрывателя, для TMB-2 — габариты самого корпуса. Для Panzerfaust 3 масса относится к оружию в комплекте и зависит от боеприпаса; масса одной гранаты не заявлена.

Старая ссылка карточки семейства M60 на страницы 3-21–3-22 заменена ссылкой на таблицу дымовых выстрелов M60/M60A1/M60A2 с белым фосфором (3-15–3-16). Другие наполнения M60 этой таблицей не охватываются.

У МУВ, МВ-5 и ВПФ добавлены только подтверждённые размеры; масса остаётся неподтверждённой. Для МУВ указаны размеры базового исполнения, без переноса на МУВ-2/3/4. Старые пометки о нехватке массы/размеров в обновлённых карточках уточнены. Деревянные мины могут заметно различаться по массе и размерам: справочные значения руководства не являются допуском для каждого экземпляра.

Полный аудит охватывает все 1287 карточек. В разделе боеприпасов остаются 147 записей без раздела характеристик, включая общие справочные статьи и неподтверждённые обозначения. Ещё 28 записей без такого раздела находятся в остальных разделах. ALL_CARDS_TTX_AUDIT.csv содержит полный перечень. Наличие ТТХ не означает полноту всех параметров или независимую проверку всех старых чисел.

Версия приложения 0.3.54 (versionCode 58), версия содержимого 96. База собрана SQLite 3.45.1.

Проверки: 15 локальных тестов; целостность SQLite и внешних ключей; соответствие всех тел карточек и источников JSON и базе; сохранение идентификаторов, изображений и остальных полей; повторное применение обновления не меняет каталог; целостность ZIP и контрольные суммы файлов.
