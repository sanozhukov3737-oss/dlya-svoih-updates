# Книга карточек — v0.3.106

Версия приложения: 0.3.106, versionCode 110. Версия каталога: 147.

## Поведение

- Категория → страна / контекст → полная карточка в режиме книги.
- Свайп вправо: следующая карточка; влево: предыдущая. Вертикальная прокрутка остаётся внутри статьи.
- Вверху отображаются категория, страна / контекст, номер карточки и общее число. Есть кнопки предыдущей / следующей карточки и «Список».
- Из обычного списка книга открывается с выбранной карточки либо кнопкой «Листать как книгу».
- Список и книга используют общий SQL-конструктор фильтров и порядка сортировки. В книгу попадает вся выборка, включая карточки за пределами окна Paging в 180 строк.
- Предзагруженные страницы не записываются в историю чтения. Для моделей страниц используются отдельные ViewModelStore, которые освобождаются после ухода страницы из композиции.
- Ключи страниц — постоянные ID карточек; текущий ID сохраняется в SavedStateHandle. Тексты и изображения загружаются через существующий экран карточки.

## Выполненные проверки

- Все 15 существующих локальных Python-тестов прошли.
- База SQLite: integrity_check и foreign_key_check прошли.
- Каталог JSON, база, маркер версии и все assets побайтно совпадают с v0.3.105. Сохранены 1287 карточек; содержимое остаётся версии 147.
- В категории «Противопехотные мины», все страны: 187 карточек. Число получено непосредственно из базы; это проверка состава данных, а не запуск Android UI.

## Ограничение проверки

Попытка выполнить `:app:compileDebugKotlin :app:compileDebugAndroidTestKotlin` остановилась при скачивании Gradle 8.13: `UnknownHostException: services.gradle.org`. Kotlin/Room/Compose в этой среде не скомпилированы, APK не собран, приложение и жесты на Android не запускались.

Добавлены 5 Android-проверок, которые пока не запускались: полная выборка за пределами Paging, фильтры категории/страны и отсутствие повторов, фильтры изображений, начальная карточка/направление свайпа/границы, сохранение вертикальной позиции при возврате.

После доступной сборки Android-проверки запускаются на подключённом устройстве или эмуляторе:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

## Сборка APK и открытие папки

Из распакованной папки проекта в PowerShell:

```powershell
.\MAKE_APK.bat
explorer.exe ".\app\build\outputs\apk\debug"
```

В папке будет `app-debug.apk`; скрипт также копирует его в корень проекта под именем `DLYA_SVOIH_v0.3.106-debug.apk`.

Обновления по воздуху в этой версии не реализованы. Для них по-прежнему требуется выбрать адрес размещения пакетов и подключить сетевое обновление.
