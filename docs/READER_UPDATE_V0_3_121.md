# ДЛЯ СВОИХ v0.3.121

Единая редакция всей оставшейся партии из 1253 немедицинских карточек. Исходное состояние — каталог 150 опубликованной v0.3.120; итоговый каталог — 151.

## Изменения для читателя

- Изменены основные тексты 949 карточек, предварительные описания — 162. Уже подходящие тексты сохранены после проверки.
- Для 46 моделей подготовлены индивидуальные описания происхождения, внешнего вида и различий.
- Исправлены грамматические обрывы, повторение одинаковой массы и лишние объяснения о страницах документов. Полные библиографические ссылки перенесены из текста и таблиц в служебные записи, где это не меняет смысл характеристики.
- Внешний вид и история выделены в отдельные части там, где есть соответствующие факты. Короткие миномётные статьи поясняют термин «мина» и тип боеприпаса.
- В памятке о чтении карточек история прежних редакций заменена понятным объяснением моделей, семейства, комплектности и неопределённых сведений; прежний текст полностью сохранён в архиве.

## Сохранность данных

Все 1293 идентификатора, 53 страны, 39 категорий, 993 изображения, подписи, источники и связи сохранены. Тексты 20 медицинских памяток и 20 карточек первой группы v0.3.120 оставлены без изменений. Табличные значения сохраняют последовательность и все оговорки; удаляется только полная библиографическая ссылка. Числовые величины предыдущих редакций остаются в основной статье. Неизвестные даты не подменяются датой публикации; разные исполнения не усредняются. Инструкции по применению, подготовке или разборке не добавлены.

## Проверка

- 49 локальных тестов: каталог, база, числа, идентификаторы, сохранность медицинских текстов, примечаний и областей применимости характеристик.
- Сборка assembleDebug; SQLite совместим с Android, проверены целостность и внешние ключи.
- Проверка на физическом телефоне не выполнялась.

## Выпуск

Приложение 0.3.121 / 125; встроенный каталог 151; схема базы 3. Публикация одним запуском Build and publish APK после завершения всей партии. Используется прежний ключ подписи и существующий канал обновления. Избранное и история чтения сохраняются при обновлении поверх установленной версии.
