# Обновление ТТХ v0.3.70

Приложение 0.3.70, код 74; содержимое 112; SQLite 3.45.1. Проверены и дополнены ещё 100 ранее не отмеченных карточек AMMUNITION. Сохранены 1287 карточек, 53 страны, 39 категорий и 987 изображений.

Для 100 карточек сверены конкретные статьи третьего издания GICHD (2025). Для M67 / M72 сопоставлены обозначения в GICHD и таблицы наполнения армии США TM 43-0001-28. Для DM121 добавлена отдельная первичная публикация Rheinmetall VJTF от 08.01.2020. В каждой карточке сохранены точные страницы, ссылки и дата проверки.

Основные изменения:

- Добавлены типы и массы основного / целевого наполнения. В 68 карточках числовое значение непосредственно сверено с началом табличной строки GICHD. Остальные случаи проверены по тексту, диапазонам, отдельным вариантам и дополнительным первичным источникам; неизвестные величины оставлены неизвестными. Проверка статьи не означает полной комплектности всех числовых показателей.
- DM106: табличная строка повторяет дымовой DM105, поэтому не использована как наполнение осветительного снаряда. Его собственное описание даёт приблизительно 3,5 кг осветительного состава на основе магния. Число сохранено приблизительным.
- DM121: таблица GICHD печатает 1 100 г, публикация производителя — 11,5 кг для описанного там исполнения. Значение производителя привязано именно к этой публикации; марка из другой таблицы не соединена с ним как установленная. Расхождение не скрыто.
- РГН / РГО: оценка 90–110 г из совместной статьи не назначена одной модели как точная масса. Общие 530 г не перенесены на РГН с отдельной массой 310 г в FM 3-23.30.
- Краснополь: 6,4 кг относятся к исходному 152-мм 3ОФ39 по конкретной статье, не к Краснополь-М2 или ко всем 155-мм изделиям.
- LU211: 8,8 кг XF 13 333 относятся к исполнению IM. Упомянутые в статье TNT и Composition B — другие варианты; их массу не сочли одинаковой по умолчанию.
- ПТМ-1: ранее отмеченные сомнения полной массы и размеров сохранены. Табличные 1 100 г наполнения также отмечены как требующие независимой сверки.
- DM105: совместная масса разных компонентов полезной нагрузки не названа чистой массой ВВ или только дымового состава.
- 3-О-8 / 3-О-13: сведения о внутреннем изделии отделены от всей сборки; новые расчётные суммы не созданы.
- Мины M67 / M72: 21,25 г Composition A5 по армии США отделены от сокращённого обозначения RDX и округлённых 21 г в GICHD. Ручная граната M67 и ракета M72 не отождествлены с минами.
- Семейства 9М27 / 9М55: массы боевых частей и полезной нагрузки не выданы за массу чистого ВВ всех модификаций.
- 3УБР6: 123 г метательного состава не записаны как основное ВВ стального снаряда.
- Семейства Bushmaster / RARDEN / Challenger 2 / AT4: показатели привязаны к названному варианту. В Challenger 2 исправлена подпись: описание прямо называет длину L31 HESH и L34 Smoke.
- BLU-97: Cyclotol 290 г и PBXN-107 280 г сохранены как альтернативы, не смесь.
- Сообщаемый суббоеприпас Х-101: приблизительная оценка остаётся оценкой, не паспортным значением.

Рецептуры, пропорции составов, инструкции обращения, настройки и способы применения не импортированы. Старые источники сохранены; кроме одной исправленной строки Challenger 2, прежние строки карточек сохранены. Идентификаторы, изображения и остальные поля не изменены. Удалённое ранее верхнее повторное описание не возвращено.

По серии: проверены 464 из 1287 карточек, осталось 823; из них 769 боеприпасов. 115 карточек боеприпасов остаются без раздела ТТХ. Этот остаток входит в 769 и не прибавляется к нему.

Проверки: 15 Python-тестов; точное воспроизведение патча; повторное применение без изменений; сохранность прежних полей и источников; сохранение прежних статусов; 68 сверок числовых значений с документом; проверки границ модификаций; SQLite integrity_check / foreign_key_check; полное соответствие базы каталогу. Архив проверяется по CRC и SHA-256 каждого файла при упаковке и ещё раз перед выдачей. APK в этой среде не собран, запуск на Android не проверен.

Из распакованной папки проекта в PowerShell:

```powershell
.\MAKE_APK.bat
```

Сразу после окончания сборки открыть папку APK:

```powershell
explorer.exe ".\app\build\outputs\apk\debug"
```
