# Запуск v0.3.117

- Android 12+: системная заставка удерживается до готовности каталога или экрана ошибки и минимум 700 мс после создания Activity. Закрытие — затухание 180 мс. Второй экран заставки после системного не показывается.
- Android 8–11: светлый фон и прозрачный логотип внутри Compose, минимум 700 мс параллельно загрузке базы, переход 180 мс.
- Возврат в уже открытое приложение не повторяет заставку. При пересоздании Android 12+ минимальный таймер не запускается заново. Ошибка базы освобождает системную заставку и показывает прежнюю кнопку повтора.
- Светлый фон запуска #FAFAF3 одинаков в дневных и ночных ресурсах. Логотип #455E34 содержит название и помещается внутрь системной маски; иконка лаунчера не меняется.
- Значки системных панелей тёмные на светлой заставке. После запуска они следуют теме приложения, а не только настройке телефона.

## Публикация

Применить патч к существующему репозиторию, отправить main, запустить новый Run workflow без заданного тега. После успешной публикации проверять обновление внутри установленной 0.3.116. Номер приложения 0.3.117, versionCode 121; каталог и база не менялись.

## Проверка на устройстве

Холодный запуск после удаления приложения из недавних; возврат из фона; поворот; светлая тема приложения при тёмной теме телефона и наоборот. Проверить отсутствие второго логотипа, обрезки надписи и нечитаемых системных значков.
