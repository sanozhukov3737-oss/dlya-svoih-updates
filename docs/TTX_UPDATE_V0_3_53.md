# ТТХ: v0.3.53

В этом обновлении добавлены таблицы физических характеристик в 41 карточку: 5 моделей Nammo, 6 моделей Dezamet, 4 карточки артиллерийских снарядов KNDS и 26 карточек из TM 43-0001-28.

Проверялись масса изделия и габариты. Комплектация указана в названиях параметров: полный выстрел, снаряд, один модуль SOHG, изделие с транспортной пробкой, со взрывателем или без него. Для KNDS проверены отдельные варианты LU215/LU216/LU217 BB и HE BB/SMK BB ER G3; данные LU211 не подставлены в другие модели. Для M922A1 использована собственная длина 4,42 дюйма, а не длина M922. В таблицах M485 и M485A2 масса указана без взрывателя, как в источнике.

Источники и страницы сохранены в карточках и content/reference_specs_v147.json. Для M804/M804A1 подтверждены только размеры, для M781 — только масса: единица измерения длины в выбранной таблице отсутствует. Наличие раздела ТТХ не означает полноту всех характеристик.

Проверены все 1287 карточек на наличие раздела характеристик. Без такого раздела остаются 180 карточек боеприпасов; ещё 28 записей — медицинские памятки, общие статьи и инструкция ПТРК. Полный аудит: ALL_CARDS_TTX_AUDIT.csv. Старые числовые значения остальных карточек в этом обновлении заново не проверялись.

Версия приложения 0.3.53 (versionCode 57), версия содержимого 95. База собрана SQLite 3.45.1.

Проверки: 15 локальных тестов; целостность SQLite и внешних ключей; совпадение тел всех 1287 карточек и записей источников между JSON и базой; сохранение идентификаторов, изображений и остальных полей; повторное применение правки не изменяет каталог.

Сборка APK и запуск Android на устройстве в этой среде не выполнены.

Сборка в PowerShell из распакованной папки проекта:

```powershell
.\MAKE_APK.bat
```

Сразу после успешной сборки открыть папку APK:

```powershell
explorer.exe ".\app\build\outputs\apk\debug"
```

Файл: app-debug.apk. Скрипт также копирует его в корень как DLYA_SVOIH_v0.3.53-debug.apk.
