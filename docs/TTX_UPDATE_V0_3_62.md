Метрические пересчёты приблизительные. Варианты Composition B, TNT, IMX-101 и PBXN сохранены раздельно. Данные американского M107 не перенесены на KM107; значения M549A1 не перенесены на M549. Белый фосфор обозначен как дымовое наполнение, а осветительный состав M314A3 — как пиротехническое наполнение, без подмены ими массы ВВ.

NEQ из HALO указан под обозначением источника. Он не подменяет полную массу изделия, массу только основного заряда или тротиловый эквивалент. Таблицы HALO в выбранных строках не называют тип ВВ — это отмечено явно. Для TM46 сохранена оговорка об общей таблице TM46 / TMN46; для POMZ-2 и POMZ-2M использованы их отдельные строки.

У M14 подтверждена полная масса 4,5 oz (≈ 127,6 г) по TM 43-0001-36, Change 2, стр. 3-8. Противоречивые 3,5 oz / 85 г из старой статьи сохранены только как замечание к ней. Размеры старого и нового источника подписаны отдельно. Для PPM-2 добавлены размеры 13,4 × 6 см по HALO; оси не названы диаметром и высотой, поскольку в таблице они не подписаны.

Army Portfolio Book 2025 изучен по архивной копии официальной публикации (https://web.archive.org/web/20250401000000id_/https://jpeoaa.army.mil/Portals/94/Documents/JPEOAAPortfolioBook_2025.pdf); в карточках сохранён адрес оригинала. В описании M927 в этой публикации есть опечатка M97; модель подтверждается заголовком страницы и её конфигурацией.

Для HGF165-3.5 масса 165 г указана только для PBXN-110, к которому она непосредственно относится в выбранной строке; массу Composition B эта партия отдельно не подтверждает. Для SOHG все новые значения относятся к одному модулю. Химические пропорции и инструкции не добавлялись.

ALL_CARDS_FILLING_AUDIT.csv охватывает все 1287 карточек. Сохранены 14 статусов checked_v155 и добавлены 30 checked_v156. Остальные 1243 строки отмечены not_reviewed_in_v156: их наполнение в этой партии не пересматривалось. Автоматическое извлечение табличных строк не проверяет полноту сведений, применимость ВВ к каждой записи или данные в обычных абзацах.

Без раздела ТТХ остаётся 116 записей боеприпасов; эта партия дополняет существующие разделы. Работа со всем каталогом продолжается.
