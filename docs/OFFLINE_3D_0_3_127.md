# Офлайн 3D в версии 0.3.127

В карточку ТМ-46 (`ref-v8-tm-46`) добавлен отдельный полноэкранный 3D-просмотр:
поворот, масштаб двумя пальцами и сброс ракурса. Модель, текстуры и Three.js
включены в APK. В просмотрщике запрещены сетевые загрузки; открытие карточки
не запускает WebView. При закрытии просмотр освобождает WebView и GPU-ресурсы.

Автор модели — Oscar Goldsworthy. Источник:
https://sketchfab.com/3d-models/tm-46-anti-tank-landmine-3f3ef18d34764342934e96c508d488b0
Лицензия — CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
Исходный GLB предоставлен пользователем. Текстуры уменьшены с 2048 до 1024,
цветовые текстуры сохранены в JPEG; буферы геометрии не изменены.
Хеши, размеры и сведения об изменениях: `assets/viewer3d/model-credits.json`.
Это визуальная авторская модель для просмотра внешнего вида.

В APK включается проверенный опубликованный каталог №190. Подпись APK
сохраняется из настроенного CI-ключа. Публикация обновляет общий `latest.json`,
сохраняя каталог №190 и его контрольные суммы.

## Сборка ресурсов

1. `python3 tools/prepare_offline_model.py /path/to/original.glb` (нужен Pillow).
2. `cd web-viewer && npm ci && npm run build`.
3. Android-сборка и тесты выполняются существующим workflow `build-apk.yml`.

Android-тест открывает реальный GLB, проверяет отрисованные треугольники при
запрещённом доступе к сети и сохраняет скриншот. Отдельно проверяются закрытие
просмотра, точная привязка к карточке и запрет сторонних адресов и путей.
