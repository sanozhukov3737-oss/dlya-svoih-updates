# Обновление ТТХ v0.3.91

Проверены ещё 22 карточки боеприпасов. Добавлена 61 строка характеристик и ограничений источников. В 14 карточках появились новые числовые сведения; в 11 добавлена масса основного ВВ с указанием модели и ограничений подтверждения. Созданы восемь ранее отсутствовавших распознаваемых разделов ТТХ. Повторно подтверждённые старые значения не засчитаны как новые. В остальных восьми карточках выполнена сверка границ источника или уточнение неверной подписи; новые числовые характеристики им не приписаны.

Сверены южноафриканская Type 72 / Non-metallic AP, китайская Type 59 AT, японские Type 63 AP, семейство Type 63 / Type 63B AT, Type 67 и Type 80, пакистанская P7 Mk1, аргентинские FMK-3, MAPG и MAPPG, румынская MSS, израильские No. 22 и No. 3, PT Mi-P, австрийские PZ MI 85M, PZ MI 88 и IMP, GIAT Lance, HB-876, южноафриканская No.69 Mk1, китайские морские M-1 / Mao-1 и M-4 / Mao-4.

Числовые дополнения атрибутированы собственным записям JMU / CISR Munitions Reference Guide. Это справочник гуманитарного центра, не паспорт изготовителя; независимое подтверждение каждого числа изготовителем не заявлено. Для моделей с неполными строками прямо указаны отсутствующие параметры. Названия Composition B и RDX/TNT приведены без состава, пропорций или рецептур. Все внесённые числа относятся к справочным внешним размерам, полной массе либо массе основного наполнения; эксплуатационные параметры не добавлялись.

Противопехотная японская Type 63 отделена от противотанковой. Для Type 63B перенесено только собственное подтверждённое наполнение; диаметр и полная масса Type 63 варианту B не назначены. Для южноафриканской Type 72 использована её собственная строка, не китайские Type 72B / Type 72C. Данные отдельной HB-876 и Lance не смешаны с массами контейнеров и носителей. Для No. 3 не использованы размеры или наполнение No. 4 либо ПМД-6. Для P7 Mk1 параметры отдельной гранаты не объявлены паспортом полной мины.

В строке FMK-3 CISR обе массы подписаны граммами. Они не перенесены в качестве подтверждённых масс и не исправлены на килограммы догадкой. Добавлены опубликованные внешние размеры и название наполнения, а проблема единиц обозначена явно. У No. 22 одинаковые 114 мм в полях Length и Height сохранены именно как поля источника с оговоркой; из них не выведены диаметр, ширина или полный согласованный габарит. У MSS значение основного ВВ 30 г атрибутировано справочнику и помечено требующим независимой сверки, без выдуманного исправления.

Для PT Mi-P использована собственная строка противотанковой мины с полной массой 10 кг. Статья предоставленного справочника о другом комплекте не стала источником её полной массы или наполнения. В PZ MI 85M собственная числовая графа пуста; характеристики PZ MI 88 или ATM 2000E ей не назначены. У PZ MI 88 и IMP не найдено нового основного наполнения в собственных строках. Эти три карточки не засчитаны как получившие новые числа.

Для южноафриканской No.69 Mk1 перечитана её собственная статья в приложении HRW Still Killing (1997). Она подтверждает самостоятельное исполнение и связь с Valmara 69, но не отдельный числовой паспорт. У MAPG и MAPPG перечитан раздел аргентинского производства Landmine Monitor 2000; он подтверждает оба обозначения, но не массу, размеры или наполнение. Числа соседних моделей не перенесены. Поиск отдельного паспорта для этих трёх карточек остаётся открытым.

Для морских M-1 и M-4 повторно прочитаны собственные строки разделённой таблицы 1 исследования U.S. Naval War College Chinese Mine Warfare (2009), физические PDF-страницы 21–24. У M-1 числовые поля внешних размеров и наполнения не заполнены. У M-4 уточнена прежняя подпись значения 600 кг: оно стоит в объединённой графе Dimensions/Warhead без отдельного обозначения вида массы. Поэтому значение сохранено с этой оговоркой, а прежнее заявление об отдельно подтверждённой полной массе снято. Значения C-6, EM-52, соседних морских мин и вариантов M-4A / M-4B не назначены этим двум карточкам. Новые числовые сведения для них не заявлены.

Всего источники сверены для 1125 из 1287 карточек. Осталось 162 для первой проверки: 130 боеприпасов, два ПТРК, десять СВО и 20 медицинских карточек. Среди оставшихся боеприпасов 49 без распознаваемого раздела ТТХ. Статус проверки означает сверку прочитанного источника, а не заполненность всех полей или независимое паспортное подтверждение. Вновь явно отмеченные пробелы остаются задачами дальнейшего поиска.

Версия приложения 0.3.91, код 95, содержимое 133. База пересобрана совместимым SQLite. Проверены воспроизведение изменения, повторное применение без изменений, совпадение JSON и SQLite, integrity_check и foreign_key_check. Все 15 локальных тестов пройдены. Все 1265 карточек вне партии остались неизменными. Прежние источники и все 910 файлов изображений сохранены. Исправления открытия локальной базы и удаления верхнего повторного описания сохранены. APK здесь не собирался; запуск на Android не проверялся.

Из распакованной папки проекта в PowerShell:

```powershell
.\MAKE_APK.bat
explorer.exe ".\app\build\outputs\apk\debug"
```

## Проверка комплекта

1287 карточек, 53 страны, 39 категорий и 987 записей изображений. Сохранены все 910 файлов изображений. Сверены выбранные собственные строки и исторические разделы, не целиком все справочники. Архив проверяется по CRC и контрольным суммам всех файлов; запуск на Android и сборка APK не заявлены.
