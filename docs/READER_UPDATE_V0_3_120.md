# ДЛЯ СВОИХ 0.3.120

Версия APK: 0.3.120, versionCode 124. Встроенный каталог: 150.

Первая углублённая редакция 20 карточек советской и российской номенклатуры: ПМН, ПМН-2, ПМН-3, ПМН-4, ПФМ-1, ОЗМ-72, МОН-50, МОН-90, ТМ-62М, ТМ-57, ТМ-72, ТМ-83, ПТМ-3, ПТМ-1, ПМД-6, ТМ-62П3, Ф-1, РГД-5, РГН, РГО. Переписаны описания внешнего вида, происхождения и различий моделей. Обозначения характеристик приведены к общему виду. Расхождения справочников и границы применимости величин оставлены видимыми.

Для всех карточек: кнопка «Чтение», сохраняемый размер текста 90–150%, буквальный поиск внутри статьи с подсветкой и переходами между фрагментами, оглавление и быстрые переходы к разделам. Примечания из раздела источников не участвуют в поиске по статье.

Родственные модели выводятся перед остальными карточками категории. Нажатие открывает карточку; отдельная кнопка «Сравнить» сохраняет прежнюю функцию сравнения. Группы заданы явно для ПМН, МОН, ТМ-62, ПМД-6/ПМД-6М и РГН/РГО. В остальных рекомендациях модели с общей страной происхождения имеют приоритет.

Галерея: кнопки приближения, уменьшения и сброса масштаба; миниатюры для карточек с несколькими изображениями; подробная подпись и сведения о правах открываются отдельно. При увеличенном изображении свайп перемещает изображение, при исходном масштабе — листает галерею. Новые фотографии в этой редакции не добавлены.

Все 1293 идентификатора, 993 изображения, ссылки, категории, привязки к странам и 20 медицинских текстов сохранены. APK подписывается прежним ключом; обновление устанавливается поверх предыдущей версии.

Проверки: локальные тесты каталога, источников, обновлений и Java-проекции статьи; отдельная проверка реального поиска и SQL-порядка родственных моделей; assembleDebug. Проверка на физическом телефоне не проводилась.
