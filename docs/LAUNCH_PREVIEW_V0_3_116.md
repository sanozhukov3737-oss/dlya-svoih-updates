# Заставка и проверка обновления 0.3.115 → 0.3.116

Версия приложения 0.3.116, versionCode 120. Каталог №148, 1293 карточки; содержимое базы и фотографии не меняются.

Заставка использует существующий локальный логотип, текущую тему и фактический номер версии установленного APK. База начинает открываться сразу. Минимальная длительность около 900 мс, переход в каталог — 220 мс. Возврат в открытую Activity не запускает заставку повторно; сохранённый срок не сбрасывается при повороте экрана. Если база сообщает ошибку, она показывается без ожидания заставки. На Android 12+ системная заставка имеет согласованный фон.

## Проверка на телефоне

1. На телефоне оставить установленную 0.3.115.
2. Применить архив изменений в DLYA_SVOIH_GITHUB, создать коммит и отправить main.
3. Запустить новый Build and publish APK на main. Tag оставить пустым; changes: «Заставка при запуске. Версия 0.3.116.»
4. Дождаться Success и опубликованного app-0.3.116.
5. В установленной 0.3.115 открыть обновления и проверить наличие новой версии приложения. Должна появиться 0.3.116.
6. Скачать обновление из приложения, разрешить Android установку из этого источника, если система запросит, и подтвердить установку.
7. Открыть приложение: заставка должна показать «Версия 0.3.116», затем каталог. Избранное и история должны сохраниться.
8. Вернуться из фона: повторной заставки быть не должно. Проверить ещё раз обновления: установленная версия должна быть актуальной.

Проверку на реальном телефоне выполняем после публикации: успешная локальная сборка сама по себе не подтверждает установку обновления по воздуху.
