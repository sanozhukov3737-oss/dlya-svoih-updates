# Обновление справочных данных — 0.3.75

Версия приложения 0.3.75 (код 79), версия содержимого 117.

## Обновление v0.3.75

Проверены источники и дополнены 28 минных карточек: 101 справочная строка, внешние размеры по подписанным рисункам NAVEODTECHDIV и отдельные показатели N.E.W. Внесены 4 новые таблицы в разделы характеристик, включая один новый раздел ТТХ.

Всего проверены источники 705 из 1287 карточек. Осталось проверить 582, из них 528 боеприпасов. 108 карточек боеприпасов без раздела ТТХ входят в остаток. Проверка источников не равна полному числовому паспорту.

Разделены VS-2.2 TYPE 1 / TYPE 2, VS 1.6 / MOD 1, TC/2.4 / TC/3.6 / TC/6 и комплектации BLU-91/B / BLU-92/B. Спорные размеры отмечены по источникам. N.E.W. не использовано вместо отдельной массы основного ВВ; точная марка и отдельная масса на этих листах не установлены. Значение 10 г L10A1 оставлено неподтверждённым. Болгарская TMD-1 не получила данные советской одноимённой мины.

Версия приложения 0.3.75, код 79, версия содержимого 117. Сохранены исправления открытия базы, прямой Gradle Wrapper и удаление повторного верхнего описания карточек. 15 локальных тестов прошли. APK здесь не собирался.


Сразу после сборки открыть папку с APK:

```powershell

```

## Первичные источники и границы сведений

NAVEODTECHDIV, Iraq Ordnance Identification Guide, 1 January 2004. Прочитаны оригинальные главы Landmine, Naval Mine и Scatterable из архива JMU CISR. Размерные рисунки проверены визуально, поскольку значительная часть подписей отсутствует в извлечённом тексте PDF. Сводная веб-таблица JMU использована только для обнаружения расхождений; её новые числовые поля основного наполнения в этот выпуск не переносились.

28 основных листов карточек и три дополнительных листа сверены с исходными PDF. Некоторые карточки используют один лист: всего 26 разные страницы. Индекс источника, страница и ссылка сохранены в каждой карточке.

N.E.W. — исходное энергетическое поле документа. Без отдельного пояснения состава его нельзя считать массой основного наполнения. Никакие пропорции составов, способы инициирования, установки и применения в дополнения не переносились.

checked_v169 означает проверку названного источника и конкретное дополнение. Он не означает завершённый паспорт всех вариантов семейства. Остаток учитывается по карточкам, а не по количеству исполнений.
