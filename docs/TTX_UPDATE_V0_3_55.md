# ТТХ: v0.3.55

Добавлены подтверждённые физические характеристики в 7 карточек: ТМ-39, ТМ-44, ТМД-40, ПМЗ-40, Tellermine 35, M24 и семейства ручных гранат Rheinmetall. Для каждой записи указаны источник и страницы.

Источники: US Army TM 5-223A (1951), TM 5-223C (1952), TM 43-0001-36; Rheinmetall Infantry Guide B092e0619 (2019). Перенесены только масса изделий и габариты. Масса наполнения и транспортной упаковки не используется вместо массы изделия.

Диаметр Tellermine 35 прочитан по оригинальному скану: 12½ in, а не ошибочные 12¼ in из распознанного текста. Модель T.Mi.35(S) этой таблицей не охватывается. Для ТМД-40 сохранён диапазон массы. Для ПМЗ-40 не заявлена единая высота: она зависит от конфигурации. Для ТМ-44 подтверждена только приблизительная масса; размеры ТМ-41 сюда не перенесены.

У M24 разделены масса комплекта без включённых батарей, масса ракеты и длина ракеты. Неоднозначное значение диаметра в руководстве не переносилось. У Rheinmetall массы OffHGr 85/86 и SplHGr 85/86 указаны отдельно; они не распространены на учебные исполнения или ShockMax. Размеры Hand Grenade 86 приведены по таблице семейства; неоднозначные диаметры Hand Grenade 85 не добавлены.

Аудит всех 1287 карточек сохранён в ALL_CARDS_TTX_AUDIT.csv. В разделе боеприпасов остаются 140 записей без раздела характеристик, включая общие статьи и неподтверждённые обозначения. Наличие раздела ТТХ не означает полноту всех параметров.

Версия приложения 0.3.55 (versionCode 59), версия содержимого 97. База собрана SQLite 3.45.1.

Проверки: 15 локальных тестов; целостность SQLite и внешних ключей; соответствие тел карточек и источников JSON и базе; сохранение идентификаторов, изображений и остальных полей; повторное применение обновления не меняет каталог; целостность ZIP и контрольные суммы файлов.

Сборка APK и запуск на Android в этой среде не выполнены.

Из распакованной папки проекта в PowerShell:

```powershell
.\MAKE_APK.bat
```

Сразу после успешной сборки открыть папку APK:

```powershell
explorer.exe ".\app\build\outputs\apk\debug"
```

Файл: app-debug.apk. Копия в корне: DLYA_SVOIH_v0.3.55-debug.apk.
