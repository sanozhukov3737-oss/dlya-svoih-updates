## Отбор и ограничения

- Исходно выделено 1158 записей-кандидатов; повторы одного обозначения между PDF объединены. Разные изделия с похожими индексами не объединялись по одному визуальному сходству.
- 38 спорных обозначений или вариантов оставлены в `excluded` внутри overlay. В том числе не перенесены неоднозначные транслитерации исторических ФАБ и противоречия СПМ/СМП, УПМ/УМП.
- В каталоге БПЛА использованы заголовки самих страниц. Его оглавление отстаёт от вставленных страниц; привязки не строились по одному напечатанному номеру из оглавления.
- Из учебника «МПД для БЛА…» не перенесены инструкции и схемы. Самостоятельные дополнительные индексы из проверенных заголовков не установлены.
- Не импортированы инструкции по применению, сборке, установке, обезвреживанию, тактике, радиоканалам или уязвимостям. Разрезы и изображения внутренних устройств отсеяны.
- Фотографии боевого варианта не подставлены вместо неподтверждённого инертного исполнения. Для части записей нет отдельной пригодной иллюстрации; похожие изделия их не заменяют.
- Размеры изображений не увеличены, исходная окраска сохранена. Авторы и лицензии отдельных иллюстраций в PDF не установлены; свободная лицензия не заявлена.
- PDF целиком не включены в приложение. Источник каждой записи содержит имя документа, точную PDF-страницу и SHA-256.
- 3D-пакет, реестр моделей, геометрия и материалы в этой партии не менялись.

## Проверки

- Полная проверка структуры JSON, размеров, реального декодирования всех новых изображений и миниатюр.
- SQLite 3.45.1: integrity_check, foreign_key_check и FTS integrity-check прошли.
- Все новые записи присутствуют в FTS; поисковое представление построено теми же Java CatalogSearch/ReaderContent, что использует приложение.
- Проверены различия F1 Австралии / советской Ф-1, SHARK / MiniShark, МОН-100 / МОН-100.1, МПМ-Э / ТМК-2ВЗ.
- Файлы пустого экспорта пересозданы и заново декодированы.
- Android-импорт и отображение нового каталога на телефоне/эмуляторе пока не проверены. APK не собирался, feed и публичные выпуски не менялись.

## Воспроизведение

Overlay применяется только к исходному JSON каталога 197 с совпадающей SHA-256. Повторное применение поверх каталога 198 отклоняется. `tools/apply_pdf_import_198.py` формирует подготовленный JSON, штатный `tools/build_catalog.py` — SQLite, `tools/verify_pdf_import_198.py` сравнивает результат с исходным 197, переданным через `--baseline`. Проверка выполняется до замены исходника на подготовленный каталог.

Одноразовый workflow переносит SHA-проверенные наружные изображения из транспортных частей, выполняет те же проверки и сохраняет подготовленные файлы в этой ветке. Транспортные части удаляются из итогового дерева; исходный пакет остаётся в истории коммита подготовки. Это не workflow публикации приложения.

Проверка итоговых обрезок исключила ещё шесть изображений с фрагментами разреза/внутреннего устройства. Запись УБР-354А (53-УБР-354Б) вместе с её изображением перенесена в спорный список: соответствие индексов требует уточнения. Итог: 1020 новых записей и 536 наружных иллюстраций.

Во второй партии исправлена ошибочная привязка PDF-стр. 140 к электронной плате MIB: это другой предмет. Ссылка отнесена к отдельной новой карточке инженерного боеприпаса МИБ.
