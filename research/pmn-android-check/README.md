# Проверка пробной ПМН в Android-просмотрщике

Отдельная проверочная ветка `research/pmn-android-check-20261022` от исходников `aaf393463cebe04e179487036165ac856c23886e`.

Генератор воспроизводит ранее одобренную модель внешнего вида. Обязательная SHA-256 GLB: `5875ba897efc6e62512238edb9b210705940e782fc8a37688fb1dbc72dd106fa`.

`prepare.py` в одноразовом checkout добавляет её только в отдельную debug-сборку `ru.dlyasvoih.app.pmnvisualcheck`. Исходный просмотрщик, JavaScript, материалы и модель сверяются до сборки. Файл в исследовательской подборке не привязывается к рабочим карточкам. Выпуск APK и обновление OTA не входят в эту проверку.

Одна проверочная сборка запускается на свежих эмуляторах API 26 и API 36. Тест получает обычный, повёрнутый, увеличенный и восстановленный кадры; проверяет отображение маркировки, заблокированную сеть, настоящий свайп, двухпальцевое увеличение и сброс положения. После получения кадров требуется ручная визуальная оценка. Сам факт успешного чтения геометрии не считается такой оценкой.

Времена перерисовки относятся к программному GPU эмулятора и не являются измерением FPS физического телефона. Источники и CC BY-SA 3.0 указаны в метаданных генератора.
