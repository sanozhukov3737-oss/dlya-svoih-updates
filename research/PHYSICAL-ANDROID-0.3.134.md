# Проверка на физическом телефоне — 0.3.134

Здесь нет USB, подключённого телефона, ADB или KVM. Удалённый KVM Android в
GitHub Actions проверяет настоящий Android, но не заменяет физический телефон.
Результат физической проверки пока отсутствует.

На исходном Windows-ПК открыть PowerShell в корне проекта. В Android Studio →
SDK Manager → SDK Tools установить Android SDK Platform-Tools. На телефоне
включить USB debugging, подключить USB и разрешить именно этот компьютер.

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb devices -l
# SERIAL заменить точным серийным номером строки со статусом device.
py -3 tools/check_physical_android.py --adb "$adb" --serial SERIAL --phase before --label favorites
```

Перед командой открыть «Избранное» на установленной 0.3.133. Добавить две
легко узнаваемые карточки, если избранное пусто. Отдельно открыть «Тема и размер
текста» и записать состояние ещё одним снимком:

```powershell
py -3 tools/check_physical_android.py --adb "$adb" --serial SERIAL --phase before --label appearance
```

На 0.3.133 открыть меню → «Обновления» → «Проверить приложение» → «Скачать
приложение». Ожидается 0.3.134, около 138 МБ. После проверки APK нажать
«Установить обновление», при необходимости разрешить установку из «ДЛЯ СВОИХ»
и подтвердить обновление в Android. Данные приложения не очищать.
Если после разрешения Android вернулся в приложение, ещё раз нажать
«Установить обновление».

После запуска проверить те же избранные карточки, тему и крупный текст.
Сохранить два снимка с `--phase after`, метки `favorites` и `appearance`.
Если на телефоне уже 0.3.134, начинать сразу с `after`; не откатывать приложение
и не удалять его. Проверка сохранения данных на таком телефоне задним числом
не подтверждается.

Отключить Wi-Fi и мобильные данные. Найти `TM46`, `PMK40`, `SMi35`, `PMN2`;
открыть карточки, перелистнуть соседнюю и вернуться. В ПМН-2 открыть обе
фотографии, увеличить и сбросить масштаб. Проверить каталог 195 и новые карточки.
Сохранять каждый нужный экран:

```powershell
py -3 tools/check_physical_android.py --adb "$adb" --serial SERIAL --phase after --label gallery --require-offline
```

В 3D проверить M14, ПМН-2, M16 и британскую дрейфующую мину. Для каждой
сохранить `*-initial` и `*-rotated`: модель видна на фоне, рельеф читается,
цвет не пропал, жест вращает её. У M14, ПМН-2 и M16 сохранить видимую пометку
об условной окраске; авторство и лицензии доступны в сведениях о модели.

Скрипт только читает данные через ADB и сохраняет файлы в
`build/physical-android-0.3.134/`. Он проверяет физическое устройство,
пакет/версию и SHA-256 реально установленного APK, записывает снимок, XML,
пакет, свойства, сетевое состояние и crash log. Он не объявляет ручные
функциональные проверки успешными и не читает закрытую базу без root.
Результаты могут содержать личные данные: не загружать их в публичный репозиторий.
