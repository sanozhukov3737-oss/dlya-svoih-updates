## Сборка и CI

В `.github/workflows/build-apk.yml` обычная сборка заменяет восстановление
каталога 190 на сборку из полного `content/catalog.json`. JDK настраивается до
расчёта поисковых полей, production SQLite ограничен версией 3.45.1.
Сертификат восстановленного закрытого ключа теперь проверяется точным SHA-256,
а обход проверки первоначальной публикации отключён для следующих выпусков.
Версии опубликованных APK/каталога нельзя переиспользовать.

`tools/run_android_emulator.py` владеет одной новой группой процессов
KVM-эмулятора. Загрузка ограничена 600 секундами, команда проверки — 1200,
`adb emu kill` — 8, TERM — 10 и KILL — 5. Записываются emulator.log и
lifecycle.json. Чужие эмуляторы не завершаются. Этот же способ подключён к
штатной сборке, её команды вынесены в `tools/release_android_checks.sh`.
Перед старой baseline-версией удаляется только debug-пакет на новом эмуляторе,
чтобы Android не отвергал downgrade с текущего instrumentation APK.

При первом запуске нового сценария AVD был создан не в каталоге, который
искал emulator: `Unknown AVD name [recovery134]`. Приложение не запускалось,
результат не засчитан. Сохранены `android-ota-attempt1-job.log` и каталог
`android-ota-attempt1/`. Введён один явный `ANDROID_AVD_HOME`; путь вычисляется
через доступный на уровне job контекст `github.workspace`.

Локально прошли 29 применимых проверок: updates 9, feed 5, search 10,
reader navigation 1, DEMZ 2, handbook 2. Сохранены журналы всех групп.
YAML обоих рабочих workflow разбирается; Python компилируется, shell прошёл
`bash -n`. Компиляция не считается Android-проверкой.

Новый сценарий `tools/recovery_app_update_134.py` использует публичный feed,
кнопки приложения и системный PackageInstaller. ADB устанавливает только
baseline 0.3.133; новый APK через ADB в этом сценарии не устанавливается.
После обновления сравниваются избранное, настройки, полный каталог и все
прежние ID/rowid, затем отключается интернет и повторяются поиск, карточки,
галерея/масштаб, навигация и четыре модели с начальным и повёрнутым видом.
