# Проверка каталога 195 → 196

Проверена полная опубликованная база приложения 0.3.134: 1697 карточек,
1600 ссылок на иллюстрации, 5454 ссылки на источники. Пустых обязательных текстов,
повреждённых файлов изображений и нарушений связей не обнаружено.

## Исправления

- В 177 статьях из переводного справочника убрана шаблонная фраза, в том числе
  нарушавшая согласование рода. Повтор обозначения перенесён в примечания.
  Производитель и страна по-прежнему атрибутированы предоставленному источнику.
- Пять таблиц с тремя или четырьмя колонками приведены к поддерживаемым двум.
  Все исходные ячейки и значения сохранены; проверен реальный Java-парсер приложения.
- В трёх семействах KNDS подписаны варианты перед таблицами. Одинаковые значения
  разных вариантов сохранены, а не удалены как повторы. Порядок сверялся с вкладками
  официальных страниц производителя, перечисленных в `changes.json`.
- Уточнены шесть названий разных изделий M23, M26 и M69.
- Объединены дубли ТМ-124 и M430A1. У ТМ-124 сохранены оба уже опубликованных вида.
  У M430A1 сохранены все источники и исходная дополнительная статья в служебных
  сведениях; повтор идентичного изображения исключён.
- Исправлены девять привязок иллюстраций. Пять внешних видов извлечены из
  армейского TM 43-0001-28; координаты, страницы, происхождение и хеши находятся
  в `illustrations.json`. Для 40-мм M662 использован уже опубликованный общий вид
  M583A1/M661/M662 с правильной страницы 606. У XM930, M908 и учебной Mk 1A1
  удалены не соответствовавшие им таблица, упаковочные данные и чужая иллюстрация.

Итог: 202 изменённые карточки, 2 объединённых дубля, 1695 активных карточек,
1596 ссылок на изображения, 5460 ссылок на источники. Одинаковых заголовков нет.
Все 1309 табличных блоков принимает штатный парсер. Проверены декодирование
3154 используемых файлов полных изображений и миниатюр, целостность SQLite,
внешние ключи и постоянные идентификаторы.

## Сохранение пользовательских данных

Объединение не меняет постоянные ID оставшихся карточек и использует штатную
политику ContentUpdater: из обычного каталога дубли исчезают; старые карточки,
сохранённые в избранном или истории, остаются архивными и доступными.
Перенесённым источникам и дополнительному изображению присвоены новые ID,
чтобы сохранённые архивные записи не конфликтовали при @Insert на Android.
Отдельные Android-тесты импортируют реальный ZIP поверх точной публичной базы
195, проверяют оба дубля, избранное, место чтения и повторное открытие базы.
Результат выполнения этих тестов публикуется артефактом GitHub Actions;
публичный канал обновления открывается только после их успеха.

## Границы проверки

Все строки и файлы проверены автоматически; визуальная сверка с первоисточником
выполнялась для подозрительных привязок, а не для каждого из 1596 изображений.
71 группа общих изображений остаётся списком для редакционной проверки, а не
списком доказанных ошибок. Семейства, национальные исполнения, обзорные и подробные
статьи не объединялись только на основании одинакового рисунка. В частности,
общий индекс M662 у 105-мм и 40-мм изделий не делает их одной моделью.
Краткость статьи сама по себе не исправлялась добавлением неподтверждённых сведений.
Независимая проверка каждого технического утверждения не выполнялась.

Все 20 медицинских карточек полностью совпадают с опубликованным каталогом 195;
3D-модели и приложение не изменены. Старый тест `test_medical_reader_revision.py`
сравнивает структуру с прежней редакцией 151 и уже не принимает опубликованную
карточку `first-aid-bleeding`; его результат не выдаётся за проверку этой версии.
Вместо изменения медицинского текста проверяется точное сохранение всех 20 карточек.

Поиск восьми отложенных новых фотографий не возобновлялся. Частная подборка ПНИ-1
не включена. Для новых рисунков использован труд федерального правительства США;
фотографии с неустановленными правами заново не публикуются.
