# Сравнение карточек — приложение 0.3.135

Исходная точка — приложение 0.3.134 и опубликованный каталог 197. В исходном
коде уже были фильтр по разделу/категории и сопоставление строк по подписям.
Список сравнения ограничивался 12 полными статьями, экран показывал две карточки,
заголовки прокручивались вместе с характеристиками.

## Изменения

- Выбор из всей текущей категории с поиском по названию. Запрос возвращает
  лёгкие превью; полные тексты загружаются только для выбранных карточек.
- Две или три карточки, включая исходную. Повторный выбор того же ID,
  другой раздел/категория и архивные записи исключены. Загрузка выбранного
  ID дополнительно проверяется в репозитории.
- Закреплённые заголовки с миниатюрами. Одна горизонтальная прокрутка движет
  сразу заголовки и значения; названия полей остаются видимыми. Колонки
  сохраняют читаемую минимальную ширину.
  Описания раскрываются отдельно от характеристик.
- Именованные поля с единицами массы/длины сопоставляются с сохранением самих
  единиц у каждого значения. Числа не пересчитываются и не дополняются.
  «Масса без крышки» остаётся отдельным полем; индивидуальные названия вариантов
  сохраняются. Отсутствующее значение явно подписано.
- Выбор карточек и открытое сравнение сохраняются при смене конфигурации.

Каталог 197, база, иллюстрации, медицинские тексты и 3D-файлы остаются прежними.
Контрольные суммы данных зафиксированы в `docs/releases/app-0.3.135.json`.

## Проверка и публикация

Первый workflow выполняет 30 проверок на хосте, собирает оптимизированный
недебажный APK с прежним сертификатом и запускает четыре Compose-теста
на Android 11. Они проверяют порядок полей, отсутствующие значения, прокрутку,
закреплённые заголовки, три колонки, предел выбора и поиск за пределами первых
12 кандидатов с исключением другой категории.

Затем на отдельном эмуляторе устанавливается опубликованный APK 0.3.134
и подготавливается фикстура его сохранённых данных после каталога 197:
точная публичная база и медиа из пакета 197, избранное, место чтения и настройки.
Фикстура устанавливается через root только на этом временном эмуляторе.
Новый подписанный release-APK ставится командой `adb install -r`. База и
пользовательские записи сравниваются до и после установки. Сам импорт
каталога 197 повторно не моделируется: он проверен при его выпуске.

Фактический release-интерфейс проверяется через UIAutomator на экране
360×640 dp, включая три карточки и масштаб системного шрифта 1,3. Снимки
и сведения о сборке сохраняются в этой папке. После просмотра этих снимков
публикуется тот же проверенный APK; смена ключа подписи не выполняется.
Штатное предложение каталога 197 сохраняется в `latest.json`, меняется
только предложение версии приложения.
