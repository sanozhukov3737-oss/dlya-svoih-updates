## Исходники и сборка

`content/catalog.json` — полный редактируемый исходник каталога 195.
`app/src/main/assets/database/guide-v29.db` — проверенная база опубликованного APK.
Все 1426 ID и rowid каталога 190 сохранены. JSON восстановлен из полной базы;
обратная сборка сравнена по всем логическим таблицам, включая поисковые поля.

Нужны JDK 17, Android SDK, Python 3 с Pillow и SQLite не новее 3.45.1 для
production-базы. На Ubuntu 24.04:

```bash
sudo apt-get install python3-pil
/usr/bin/python3 tools/build_catalog.py
/usr/bin/python3 -m unittest discover -s tools -p test_updates.py
bash gradlew :app:assembleRelease
```

Для совместимого подписанного APK использовать существующий закрытый ключ в
GitHub Actions или `tools/sign_combined_update.cmd` на исходном ПК. Не создавать
замену ключу. Для следующего выпуска увеличить версию приложения/каталога:
публичные файлы 0.3.134 и каталога 195 уже зафиксированы.

Штатная сборка теперь использует полный JSON. Старый восстановительный
`tools/restore_packaged_catalog.py` сохранён для истории; запускать его в обычной
сборке не нужно. Формирование поисковых полей использует непосредственно Java
`CatalogSearch` и `ReaderContent` из приложения.
