Android продолжает загрузку в фоне. После проверки коллекция работает без сети.
Пакет занимает 1,28 ГБ одним сжатым файлом, без второго распакованного комплекта.

«Управление» → «Удалить модели» освобождает место, сохраняя карточки, фотографии,
избранное, место чтения и тему. Коллекцию можно скачать снова. После обновления
с 0.3.138 встроенные модели заменяются отдельным пакетом; автоматически он
не скачивается. Отмена и повреждённая загрузка сохраняют установленную коллекцию.

Раздел «Обновления» позволяет включить или выключить уведомления о новых
версиях приложения и каталога. Android 13+ спрашивает разрешение по кнопке
«Включить уведомления». Проверка выполняется в фоне примерно раз в шесть часов
при наличии сети; время выбирает Android. Повторные уведомления об одной версии
не отправляются. Нажатие открывает обновления; APK устанавливается по выбору пользователя.

## Исходники и сборка

`content/catalog.json` — полный редактируемый исходник каталога (в этой подготовленной ветке — 198; опубликованная база — 197).
`app/src/main/assets/database/guide-v29.db` — соответствующая подготовленная база; публичный выпуск по-прежнему использует каталог 197.
Все 1695 карточек сохранили ID и rowid каталога 196. В версии 197 дополнены
153 кратких описания, для 25 карточек добавлены исторические сведения со ссылками.
Проверка охватила 71 группу общих изображений; уточнены 43 подписи, удалена
одна привязка к другой модели. Пять записей оставлены краткими из-за нехватки данных.
При обновлении самого каталога медицинские тексты и 3D-модели не менялись. Проверены целостность базы,
поиск и импорт реального пакета на Android 11.

Архив дополнительных GLB находится в предварительном выпуске
`models-0.3.138-inputs`; исходный реестр — `content/models-0.3.138.json.gz`.
Для небольшого APK подготовка восстанавливает полный реестр и индекс карточек
без скачивания геометрии. Каноническое описание отдельного пакета —
`content/model-pack-1.json`. Сборка исключает GLB и отказывается использовать
старый частичный реестр.

Нужны JDK 17, Android SDK, Python 3 с Pillow и SQLite не новее 3.45.1 для
production-базы. На Ubuntu 24.04:

```bash
sudo apt-get install python3-pil
/usr/bin/python3 tools/build_catalog.py
python3 tools/prepare_optional_models139.py
/usr/bin/python3 -m unittest discover -s tools -p test_updates.py
bash gradlew :app:assembleRelease
```

Сборку и Android-проверки 0.3.139 выполняет workflow
«Build optional models and update notifications 0.3.139»
(`.github/workflows/optional-models-139.yml`) с существующим закрытым ключом
в GitHub Actions. Исторический «Build and publish APK» предназначен для
прежнего совместного выпуска APK и нового каталога; для 0.3.139 используется
отдельный проверенный APK и прежнее предложение каталога 197. Исторический
`tools/sign_combined_update.cmd` предназначен для подготовленного комплекта
0.3.134 с контрольными файлами, а не для произвольного нового APK.
Для следующего выпуска увеличить версию приложения/каталога:
публичные файлы предыдущих выпусков и каталогов 195/196/197 уже зафиксированы.

Штатная сборка теперь использует полный JSON. Старый восстановительный
`tools/restore_packaged_catalog.py` сохранён для истории; запускать его в обычной
сборке не нужно. Формирование поисковых полей использует непосредственно Java
`CatalogSearch` и `ReaderContent` из приложения.
