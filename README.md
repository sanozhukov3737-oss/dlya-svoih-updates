# ДЛЯ СВОИХ — каталог №188

ДЛЯ СВОИХ — каталог №188

Создана отдельная группа «Датчики цели и платы инициации» на главном экране приложения.
Добавлены три общие справочные карточки:
1. Контактные датчики цели.
2. Неконтактные датчики цели.
3. Платы инициации — общие сведения.

Отдельные позиции по списку пользователя:
«Джоники» / «Джоник», МАГ-2, МАГ-3, «Доплер», «Искра-М».
Все пять названий имеют статус «Требует проверки». Точные модели, исполнение, происхождение, характеристики и фотографии ещё не установлены. Новые фотографии в этом обновлении не добавлены.

Всего 1324 карточки и 1306 изображений. 53 карточки без изображений; из них 8 новых. Очередь маленьких изображений: 179.
19 применимых тестов пройдены: доступность новой категории в действующем меню Java, поиск всех названий, целостность SQLite/FTS, сохранность всех 1316 прежних карточек и других категорий, обновления и ограничения импорта.
Пакет проверен: CRC, все 2456 изображений/миниатюр читаются; все 2590 исходных медиафайлов проекта сохранены байт в байт. На физическом Android не проверено.

Установка: «Обновления» → каталог №188. Затем на главном экране открыть «Датчики цели и платы инициации» → «Все страны».
Общие карточки доступны также в российском и украинском контекстах; это не утверждение о стране изготовления.
