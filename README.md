Через раздел «Обновления» старые версии сначала получают небольшой переходный
APK (versionCode 142). После его установки нужно ещё раз проверить обновление
приложения, чтобы получить полный APK (versionCode 143). Обе ступени используют
прежний сертификат и сохраняют пользовательские данные. Полная коллекция
хранится внутри APK и работает без сети.

раскрываемые сведения об авторах, лицензиях и источниках. Связи подготовлены
с 511 карточками; 44 спорных визуала остаются в общей коллекции с оговорками.
Прежние 19 GLB и все дополнительные GLB сохранены побайтно.

SHA-256 полного APK: `fa34fe2206a2c0be03dd3cf650be978385549099f9589cc7239fc3809ab60852`.
Сертификат: `2f0a0908f269bc039311edb58fca8863347f1e4c3a7cfaddd909991cf1f0b509`.
На эмуляторах Android 8 и Android 16 проверены прямая установка и переход
141 → 142 → 143 с сохранением избранного, места чтения, темы и каталога.

## Исходники и сборка

`content/catalog.json` — полный редактируемый исходник каталога 197.
`app/src/main/assets/database/guide-v29.db` — база обновления каталога 197.
Все 1695 карточек сохранили ID и rowid каталога 196. В версии 197 дополнены
153 кратких описания, для 25 карточек добавлены исторические сведения со ссылками.
Проверка охватила 71 группу общих изображений; уточнены 43 подписи, удалена
одна привязка к другой модели. Пять записей оставлены краткими из-за нехватки данных.
При обновлении самого каталога медицинские тексты и 3D-модели не менялись. Проверены целостность базы,
поиск и импорт реального пакета на Android 11.

Архив дополнительных GLB находится в предварительном выпуске
`models-0.3.138-inputs`; исходный реестр — `content/models-0.3.138.json.gz`.
Подготовка проверяет контрольные суммы архива, 615 GLB и базы, затем создаёт
реестр и компактный индекс карточек. Сборка откажется создавать неполный APK.

Нужны JDK 17, Android SDK, Python 3 с Pillow и SQLite не новее 3.45.1 для
production-базы. На Ubuntu 24.04:

```bash
sudo apt-get install python3-pil
/usr/bin/python3 tools/build_catalog.py
python3 tools/prepare_models138.py --archive /path/to/models-0.3.138-assets.zip
/usr/bin/python3 -m unittest discover -s tools -p test_updates.py
bash gradlew :app:assembleRelease
```

Совместимую подпись следующих выпусков создаёт workflow «Build and publish APK»
с существующим закрытым ключом в GitHub Actions. Исторический
`tools/sign_combined_update.cmd` предназначен для подготовленного комплекта
0.3.134 с контрольными файлами, а не для произвольного нового APK.
Для следующего выпуска увеличить версию приложения/каталога:
публичные файлы 0.3.134/0.3.135/0.3.136/0.3.137/0.3.138 и каталогов 195/196/197 уже зафиксированы.

Штатная сборка теперь использует полный JSON. Старый восстановительный
`tools/restore_packaged_catalog.py` сохранён для истории; запускать его в обычной
сборке не нужно. Формирование поисковых полей использует непосредственно Java
`CatalogSearch` и `ReaderContent` из приложения.
