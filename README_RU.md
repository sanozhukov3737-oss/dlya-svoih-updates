## Быстро сделать APK

Распакуйте SOURCE.zip. Если APK должен обновить уже установленную версию, перенесите из прежней папки `signing` и `keystore.properties`. Для обновления обязательно использовать тот же ключ подписи.

Откройте PowerShell в папке проекта и выполните:

```powershell
.\MAKE_APK.bat
```

Скрипт выбирает установленный SDK 36, очищает конфликтующий `ANDROID_SDK_ROOT`, записывает согласованный `local.properties`, проверяет JDK и останавливает старый Gradle daemon. Результат:

```text
DLYA_SVOIH_v0.3.49-debug.apk
```

Если SDK установлен только в одном месте, можно собрать напрямую:

```powershell
$env:ANDROID_HOME = "D:\Android\Sdk"
Remove-Item Env:ANDROID_SDK_ROOT -ErrorAction SilentlyContinue
.\gradlew.bat --stop
.\gradlew.bat :app:assembleDebug
```

## Полная проверка

Debug APK, unit-тесты, androidTest APK и lint:

```powershell
.\BUILD_DEBUG.bat
```

Проверка на подключённом телефоне или запущенном эмуляторе:

```powershell
.\RUN_DEVICE_TESTS.bat
```

Собрать debug APK и установить его поверх уже стоящей версии без очистки данных:

```powershell
.\INSTALL_UPDATE.bat
```

Подписанный release APK:

```powershell
.\BUILD_RELEASE.bat
```

Результат: `DLYA_SVOIH_v0.3.49-release.apk`.

## Локальные проверки исходника

```powershell
python tools\run_checks.py
```

Один прогон выполняет все поддерживаемые проверки каталога, базы, реестров и упаковки, а также
компилирует и запускает Java host-тесты, и возвращает единый код возврата. Состав проверок:
`python tools\run_checks.py --list`.

Прочие сервисные инструменты:

```powershell
python tools\build_photo_queue.py            реестр очереди визуалов
python tools\build_medical_review_package.py пакет для медицинского рецензента
python tools\extract_strings.py              инвентарь строк интерфейса
python tools\prune_snapshots.py              перенос устаревших снимков в content/history
```

В Linux-среде подготовки релиза Android-сборка не выполнялась: доступ к `services.gradle.org` закрыт, поэтому Gradle Wrapper не смог получить Gradle 8.13. На Windows используйте `MAKE_APK.bat`; установленный Android Studio JBR определяется автоматически.
